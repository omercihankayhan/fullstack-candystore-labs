Lab 3 README — HTML & CSS Interface (NEST257)
Purpose
Lab 3 introduces the front‑end foundation of the Candystore project.
You build the initial webpage layout using semantic HTML and custom CSS styling.

Learning Objectives
- Create a structured HTML page
- Apply CSS styling using external stylesheets
- Organize assets into proper folders
- Build a clean UI for later labs (JS, PHP, MySQL)
- Practice basic responsive design concepts

Folder Contents
Lab3/
│
├── index.html          # Main Candystore webpage
├── css/
│   └─ style.css       # Primary stylesheet
└── screenshots/        # UI output screenshots

Description
This lab focuses on building the visual layer of the Candystore application.
You design the page layout, apply styling, and prepare the structure that later labs will enhance with interactivity and back‑end logic.

Key features include:
- Header and navigation layout
- Product display sections
- Basic styling (colors, spacing, fonts)
- Organized folder structure

How to Run
Place the Lab3 folder under your Apache directory:
/var/www/candystore8786/

Then open:
http://localhost/candystore8786/Lab3/index.html

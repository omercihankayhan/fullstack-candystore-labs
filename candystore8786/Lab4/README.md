Lab 4 README — JavaScript & PHP Form Handling (NEST257)
Purpose
Lab 4 introduces client‑side JavaScript and server‑side PHP to handle form input, validation, and processing.

Learning Objectives
- Add JavaScript validation to HTML forms
- Send form data to PHP scripts
- Process user input on the server
- Understand GET/POST request handling
- Build interactive front‑end behavior

Folder Contents
Lab4/
│
├── js1.html            # Form page with JavaScript validation
├── action.php          # PHP script that processes form data
└── screenshots/        # Output screenshots

Description
This lab expands the Candystore interface by adding interactivity and server communication.
JavaScript handles:
- Input validation
- Basic logic
- User feedback
- 
PHP handles:
- Receiving form data
- Processing values
- Displaying results back to the user
This lab is the bridge between front‑end and back‑end development.

How to Run
Place Lab4 under your Apache directory:
/var/www/candystore8786/

Access the form:
http://localhost/candystore8786/Lab4/js1.html
Make sure PHP is enabled and Apache is running.
